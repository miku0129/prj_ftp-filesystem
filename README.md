# Setup 
## Pre-Requisites

- Docker
- VSCode (Extention: `Dev Container` is installed) 

## How to start 

1. Open devcontainer in VSCode
2. Access http://localhost in a browser
3. Excute `npm run build:css` for styling

## To connect FTP server from FTP Client
    - host: `127.0.0.1`
    - user: `user`
    - password: `pass`
    - port: `21`
